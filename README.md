# My portfolio

A small pixel-art room for my work, notes and a bit about me. Click the objects to look around.

Built with Next.js, React and TypeScript. The room art lives in an Aseprite file.

## Run it locally

You'll need Bun installed.

```sh
bun install
bun run dev
```

Open http://localhost:3000.

`bun run build` creates the production build. If you change the Aseprite file, run `bun run art` to export the room assets.
